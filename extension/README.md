# Silpo Data Extractor - Розширення для Chrome

## 📋 Опис

Це розширення для браузера Chrome, яке дозволяє витягувати дані збиральників з back-office.silpo.ua та використовувати їх на вашому сайті.

## 🚀 Встановлення

### Крок 1: Завантажте розширення
1. Завантажте папку `extension` з цього репозиторію на свій комп'ютер
2. Або клонуйте весь репозиторій: `git clone https://github.com/IvanDutsak/Copy_Robota.git`

### Крок 2: Встановіть розширення в Chrome
1. Відкрийте Chrome і перейдіть на сторінку `chrome://extensions/`
2. Увімкніть **"Режим розробника"** (Developer mode) у верхньому правому куті
3. Натисніть кнопку **"Завантажити розпаковане"** (Load unpacked)
4. Виберіть папку `extension` з завантаженого репозиторію
5. Розширення з'явиться у списку та буде активним

## 📖 Як користуватися

### Витягування даних:
1. Відкрийте [back-office.silpo.ua](https://back-office.silpo.ua)
2. Увійдіть у систему
3. Перейдіть до **"Ключові показники збиральників"** (DAMS → Ключові показники збиральників)
4. Виберіть потрібну дату (клацніть двічі на одну дату для вибору одного дня)
5. Дочекайтеся завантаження таблиці з даними
6. Натисніть зелену кнопку **"📊 Витягнути дані"** у правому нижньому куті сторінки
7. Ви побачите повідомлення про успішне збереження даних

### Перегляд даних на сайті:
1. Відкрийте сторінку `assemblers-stats.html` вашого сайту
2. Натисніть кнопку **"Завантажити дані"**
3. Виберіть себе зі списку збиральників
4. Перегляньте свої показники

## ⚠️ Важливо

- Розширення працює тільки на сторінці `back-office.silpo.ua/dams/assemblers-key-indicators`
- Дані зберігаються локально у вашому браузері
- Для оновлення даних потрібно повторно натиснути кнопку "Витягнути дані"

## 🐛 Вирішення проблем

### Кнопка "Витягнути дані" не з'являється
- Переконайтеся, що ви на правильній сторінці (Ключові показники збиральників)
- Оновіть сторінку (F5)
- Перевірте, чи розширення увімкнене в `chrome://extensions/`

### Дані не завантажуються
- Переконайтеся, що таблиця з даними повністю завантажилась
- Спробуйте вибрати іншу дату і повернутися назад
- Перевірте консоль браузера (F12) на наявність помилок
